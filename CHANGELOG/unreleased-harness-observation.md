- Give `standout-test` the observation capabilities its assertions were missing (issue #310). `TestResult::stderr()` reconstructs the error channel `App::run` would have written — a newline-terminated diagnostic, an external failure verbatim, the report of an artifact whose bytes claimed stdout — so which bytes went to which stream is assertable in-process instead of collapsing into one `error()` string. `stdout_plain()` / `stderr_plain()` return the same text with the ANSI escapes stripped by `console`, the crate that emitted them, leaving the raw accessors untouched. And `assert_page_snapshot!` pins a whole rendered page through `insta` under a name derived from a `SnapshotCase` — subject plus the axes that distinguish the cell (output mode, TTY, theme, entry point) — rather than a hand-written label, so a page that grows an extra wrong line fails a test that a list of `contains` assertions would have passed.
