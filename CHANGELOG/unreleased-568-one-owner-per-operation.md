- `standout-render`'s `truncate_end` and `truncate_middle` close a style they cut through: a truncated value whose colour was still open ends with `\u{1b}[0m` before the ellipsis. A snapshot pinning the truncated bytes of a pre-styled value gains that reset. Wrapping still cuts to continue, so a wrapped value keeps its colour across the line break (closes #568).
- **Breaking:** running a questionnaire command whose ancestor declares `--yes` or `--answers` as `global(true)` reports the reserved-name conflict `verify_command` already reported, as a usage error with exit status 2, instead of crashing on clap's debug assertions (closes #568).
- **Breaking:** the `style_as` filter rejects a style name containing `[`, `]` or `/` with a render error naming the filter and the name, rather than emitting a malformed tag. An empty name still passes the value through unstyled (closes #568).
