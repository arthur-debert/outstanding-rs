- **Breaking:** `RunError::new` refuses `RunErrorKind::Config`; build one with `RunError::config(message, error)`. Configuration, render and final-write failures now carry their cause, so a caller downcasts `source()` to `clapfig::ClapfigError`, `standout::RenderError`, `serde_json::Error` or `std::io::Error` instead of matching rendered prose. `new` still accepts `Render` and `FinalWrite`, which also have failures with no underlying error (closes #572).
- Incremental event failures are the exception and still report prose alone (#575).
