- **Breaking:** framework truncation — `{{ value | col(10) }}`, `{{ value | truncate_at(10) }}`, a table column narrower than its cell, and `truncate_to_width` — now emits the reset when a cut falls between a value's ANSI opener and its closer. A snapshot pinning the truncated bytes of a pre-styled value gains a `\u{1b}[0m` before the ellipsis. Untruncated text is untouched, unbalanced sequences included. `standout-render`'s standalone `truncate_end` / `truncate_middle` still leave the opener unclosed; #570 tracks that (closes #566, for #568).
- The `config` command escapes its output line with the same ANSI-aware function the template filters use, rather than a private copy that turned every `[` into `\[` including the ones inside an escape sequence. Config keys and file paths carry no escape sequences, so what `config` prints today is unchanged. `escape_style_tags` is now exported from `standout-render`, where the surviving definition lives; `standout` does not re-export it, so it stays internal rather than contract (closes #565).
