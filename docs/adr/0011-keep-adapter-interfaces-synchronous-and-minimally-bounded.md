# Keep adapter interfaces synchronous and minimally bounded

Resource capability interfaces are synchronous to match Standout's current dispatch model, and the Resource crate imposes no blanket serialization or thread-safety bounds. Each Resource declares its identity type, each capability owns an overridable output type, and the common error interface standardizes only not-found and opt-in conflict while preserving an associated adapter error for backend-specific failures. Concrete adapters and the Standout integration add only the bounds they require; async execution remains a separate Standout-wide design.
