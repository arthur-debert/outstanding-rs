# Let the parser classify the command line

Standout never reads the raw argument list. Every fact it needs — which command was named, whether none was, whether help was requested, whether a token is a command name or some option's value — is a read of Clap's parse result or of Clap's typed error. The rejected alternative was a lexical scan that read argv to decide the command before Clap ran; it was implemented and withdrawn. To answer the one question it existed to answer, that scan had to reimplement option-value consumption, `--` termination, inline `--flag=value`, short-option clusters, alias resolution, and the visibility of global arguments at nested levels — and it was wrong about each of those in turn, every one a thing the parser already did correctly. A partial hand-rolled scan is a parser with unknown coverage: short of writing a complete one, there is always another line that breaks it, and each break looks like an isolated bug rather than the category it belongs to. When a parse refuses a line Standout needs to understand, the lever is the declaration, not a second reader: `subcommand_negates_reqs` suspends a root's requirements when a command is named, which is what makes an installed `help` word reachable on a root that requires arguments.

The consequences follow from having one parser. Default commands are driven off the parse outcome rather than off the input: a successful parse that selected no subcommand is a naked line and takes the default, a failure whose typed kind says a command was missing inserts the default and parses again, and every other failure stays Clap's usage error unaltered. That is a fallback on the parser's own verdict, which is what separates it from re-reading the argument list when a parse fails — the latter makes a word's meaning depend on whether unrelated tokens happened to parse, and discards the diagnostic that mattered. Because nothing decides before parsing, the default-command resolver keeps the root matches it was always given. Help follows the same discipline: the word is a declared subcommand that Clap routes, `--help` and `-h` are Clap's own flags whose `DisplayHelp` Standout renders in its own template, and which command's help to show is read from the parse rather than recovered by walking tokens.
